# Project Intelligence & Guidelines: Flag Drawer (.agyrules.md)

Este documento registra los patrones, preferencias y restricciones del proyecto Flag Drawer descubiertos durante el trabajo.

## Reglas Operativas Obligatorias
- **Restriccion de comandos Git:** No ejecutar ningun comando de git directamente. Cuando se requiera interactuar con git, proporcionar al usuario el comando exacto en bloque de texto para su ejecucion manual.
- **Uso de emojis:** Evitar abusar de emojis. No incluirlos en comentarios de codigo, documentacion Markdown ni codigo de interfaces a menos que sea explicitamente solicitado.

## Patrones de Codigo y Arquitectura
- **Doble archivo de logica (Modulos vs Bundle):**
  - La logica principal reside de forma modular en `js/app.js`, `js/canvas.js`, `js/comparator.js` y `js/flags.js`.
  - El archivo `js/bundle.js` contiene la version unificada cargada por `index.html` para permitir ejecucion directa en navegadores via protocolo `file://` sin restricciones CORS.
  - Al realizar cambios en la logica de la aplicacion, debe mantenerse la sincronia entre los modulos individuales y `bundle.js`.
- **Canvas y Renderizado:**
  - Todas las operaciones de evaluacion se realizan con una resolucion normalizada de 300x200 px.
  - El contexto del canvas debe inicializarse siempre con `{ willReadFrequently: true }` para optimizar las llamadas a `getImageData`.
- **Estilo Visual Suizo:**
  - Respetar rigurosamente los lineamientos de `design.md`:
    - Grid asimetrico y limpio.
    - Sin sombras pesadas ni gradientes decorativos.
    - Tipografia sans-serif funcional (Helvetica Neue) y monospace para valores tecnicos (JetBrains Mono).
    - Paleta controlada basada en Signal Red, Black, White, Cool Grey y Deep Blue.
